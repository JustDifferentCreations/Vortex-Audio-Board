# Vortex Control Audio Board

The sound board for **Vortex Control**, a vertical pinball machine that is still in progress. An [Adafruit Audio FX Sound Board](https://www.adafruit.com/category/196) mounts on top, and an AVR16DU28 turns signals from the main board into trigger presses on the Audio FX board's trigger pins.

Board: Vortex Control Audio PCB REV 0.2, designed by [Just Different Creations](https://justdif.com) in Lufkin, Texas. See it on the [PCB-Only Builds](https://justdif.com/pcb-only-builds/) page. The other Vortex Control boards: [Vortex-Score-Display](https://github.com/JustDifferentCreations/Vortex-Score-Display) and [Vortex-Motor-Driver](https://github.com/JustDifferentCreations/Vortex-Motor-Driver).

## How it works

The Audio FX board plays a sound when one of its trigger pins (0 to 10) is pulled low. This board drives those pins from the main board's signals:

| Input (from main board) | Sound trigger |
| --- | --- |
| Power-up | Trigger 0 pulsed low for 500 ms (startup sound) |
| MC1 (PA0) held low | One of triggers 5 to 10, picked at random, held low for as long as MC1 is held (only while no other input is active) |
| MC2 (PA1) low | Trigger 1 pulsed low for 500 ms |
| MC3 (PA2) low | Trigger 2 pulsed low for 500 ms |
| MC4 (PA3) low | Trigger 3 pulsed low for 500 ms |
| MC5 (PA4) low | Trigger 4 pulsed low for 500 ms |
| MC6 to MC8 (PA5 to PA7) | Not used yet (they only block MC1's random sound) |

All inputs are active low with internal pull-ups. All trigger outputs idle high.

## Trigger outputs (AVR16DU28)

| Pin | Audio FX trigger |
| --- | --- |
| PD0 to PD7 | Triggers 0 to 7 |
| PF0 | Trigger 8 |
| PF1 | Trigger 9 |
| PC3 | Trigger 10 |

## Building and flashing

- MPLAB X IDE with the XC8 compiler (built with v3.10)
- Programmer: PICkit 5
- Pins and pull-ups are set up with MPLAB Code Configurator (MCC Melody). The `mcc_generated_files` folder is not in this repo. Open the project in MPLAB X, open MCC (it loads `AVR16DU28_AudioFX_PCB.mc3`), click **Generate**, then build and program the board.
- The sound files themselves live on the Adafruit Audio FX board and are not part of this repo.

## Status

Vortex Control is still being built, so this code will keep changing.
